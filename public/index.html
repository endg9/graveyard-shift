🧟 How the sentinel judges a mint

  1. Code present? — is there actually a contract at the address?
  2. Source verified? — Sourcify must match bytecode to published source (−25 if not).
  3. Owner? — a live owner() means one address can still rug or gate the mint (−20).
  4. Supply left? — totalSupply vs maxSupply; sold out is a −40.
  5. Slot unused? — balanceOf / hasClaimed for a probe wallet (−15 if used).
  6. Free lane? — a 0-value static call to mint()/openFree()/claim() must not revert (−30 if none answers).

Score is deterministic: same on-chain state → same score, every time. Anything the chain cannot answer is labelled unavailable, never invented.
